# Apeiron.sg Rebuild

Clean, ultra-fast, zero-bloat HTML5 & CSS website for **Apeiron Strategic Advisory**.

## Site Structure (URL Preservation)
- `/` -> `index.html`
- `/about-us/` -> `about-us/index.html`
- `/services/` -> `services/index.html`
- `/insights/` -> `insights/index.html`
- `/contact-us/` -> `contact-us/index.html`
- `/privacy-policy/` -> `privacy-policy/index.html`

## How to Deploy on GitHub Pages
1. Create a new GitHub repository named `apeiron-website`.
2. Extract and upload all files from `apeiron-website-github.zip` to the `main` branch.
3. Go to **Settings > Pages** in your GitHub repository.
4. Set **Source** to `Deploy from a branch`, choose branch `main` and folder `/ (root)`.
5. Under **Custom Domain**, enter `apeiron.sg` and click Save.
6. Enable **Enforce HTTPS**.
